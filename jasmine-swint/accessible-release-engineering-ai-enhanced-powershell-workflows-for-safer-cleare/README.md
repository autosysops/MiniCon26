# Accessible Release Engineering: AI‑Enhanced PowerShell Workflows for Safer, Clearer Deployments

**Speaker(s):** Jasmine Swint — session on the [MiniCon26](https://synedgy.com/psconfeu-minicon/) agenda.

## Abstract

Release engineering is often slowed by unclear logs, inconsistent deployment steps, and inaccessible error messages. This session shows how to combine PowerShell with AI to create accessible release workflows that improve clarity, reduce risk, and accelerate deployments. Attendees will learn how to use LMs to summarize release notes, rewrite errors into accessible language, generate remediation steps, and validate deployment artifacts.

We’ll walk through how to build PowerShell‑based release pipelines that enforce structure, readability, and accessibility ensuring every engineer can understand what’s happening during a deployment. This session is ideal for DevOps teams seeking safer, more predictable release processes.
