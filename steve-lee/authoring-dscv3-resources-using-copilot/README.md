# Authoring DSCv3 resources using Copilot

**Speaker(s):** Steve Lee — session on the [MiniCon26](https://synedgy.com/psconfeu-minicon/) agenda.

## Abstract

Lessons learned from using AI to author a DSCv3 resource.  We'll go through the experience creating some of the resources that are shipped with DSCv3, development of a SKILL.md, and attempt to create a new resource.  We'll cover design considerations, prompt authoring, leveraging a skill, and testing.
