# From PowerShell to Action

**Speaker(s):** Maik van der Gaag — session on the [MiniCon26](https://synedgy.com/psconfeu-minicon/) agenda.

## Abstract

In many automations and deployment flows, scripts are used for configuration and deployments. Within companies these scripts are being shared and copied around and saved in not 1 but many repositories. Over time they drift apart, and nobody knows anymore which version is the right one.

During this session we will cover this topic and work towards a solution. We start with a plain PowerShell script and turn it step by step into a GitHub Action that the rest of the organisation can use. We will look at how to design the inputs and outputs, how to test the script, and how versioning helps you make changes without breaking everyone else.

At the end of the session you know how to go from a script in a repository to something your teams can actually depend on.
