# Sign of the Times - PowerShell and Authenticode

**Speaker(s):** Jordan Borean — session on the [MiniCon26](https://synedgy.com/psconfeu-minicon/) agenda.

## Abstract

Explore the world of code signing and digital certificates in PowerShell. This session covers how Authenticode works in PowerShell, why it matters for security, and how to implement it in your scripts and modules. Learn to create, manage, and validate digital signatures using certificates, understand how code signing fits with Windows Defender Application Control (WDAC), and integrate signing into your CI pipelines. We'll walk through signing scripts and modules, then explore how PowerShell validates signatures and what happens when things go wrong. Whether you're securing production automation, distributing modules, or building a WDAC-friendly toolchain, you'll master the practical aspects of PowerShell code signing and how to troubleshoot signature-related issues.

Key Takeaways:

+ Understand Authenticode concepts and digital certificate requirements
+ Sign PowerShell scripts and module files correctly
+ Validate signatures, verify certificate chains, and align with WDAC policies
+ Integrate script signing into CI pipelines with timestamping
+ Troubleshoot common signing and certificate lifecycle issues
