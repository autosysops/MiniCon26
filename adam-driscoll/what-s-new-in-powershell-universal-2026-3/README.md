# What's new in PowerShell Universal 2026.3

**Speaker(s):** Adam Driscoll — session on the [MiniCon26](https://synedgy.com/psconfeu-minicon/) agenda.

## Abstract

In this session we'll look at the new features in PowerShell Universal 2026.3. We'll talk about new scale out job execution using Devolutions Agent, redesigned Admin Console UI, a new AI agent chat experience and a few other features that continue to drive the best solution for teams building tools in PowerShell.
