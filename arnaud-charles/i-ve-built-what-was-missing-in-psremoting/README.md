# I've built what was missing in PSRemoting

**Speaker(s):** Arnaud Charles — session on the [MiniCon26](https://synedgy.com/psconfeu-minicon/) agenda.

## Abstract

Ever since I've been working in an environment with Core servers, logging in has been made easier with a simple PowerShell function, but when it comes to navigating the directory tree, getting information about files, or manipulating them, it's still a hassle and requires a lot of concentration and memory.
So I created two modules with no external dependencies—just PowerShell—to provide a Vim-like editor and a file explorer.
